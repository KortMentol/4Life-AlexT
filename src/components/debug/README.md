# Модуль: Performance Debug

## @description

Этот модуль предоставляет два компонента для мониторинга производительности приложения в реальном времени: `PerformanceDebug` для десктопных устройств и `PerformanceDebugMobile` для мобильных. Панели отображают ключевые метрики, такие как FPS, время кадра, и статический "балл производительности", рассчитанный на основе характеристик устройства.

## @author

Kort

## @version

1.0.0

## @see

- `src/utils/devicePerformance.ts`: Утилита, отвечающая за сбор характеристик устройства и вычисление балла производительности.
- `src/App.tsx`: Место, где компоненты рендерятся в зависимости от типа устройства.

## Компоненты

- **`PerformanceDebug.tsx`**: Десктопная версия. Плавающая, перетаскиваемая панель с двумя режимами (компактный и развернутый).
- **`PerformanceDebugMobile.tsx`**: Мобильная версия. Панель, закрепленная внизу экрана, которая может быть свернута или развернута свайпом/тапом.

## Ключевые метрики

- **FPS (Frames Per Second):** Частота кадров.
- **Frame Time:** Время рендеринга одного кадра в миллисекундах.
- **Performance Score & Tier:** Статическая оценка производительности устройства (0-100) и уровень (low, medium, high), вычисляемые при инициализации.
- **Device Specs:** Детальная информация об устройстве (RAM, CPU, GPU и т.д.).

## @usage

Компоненты импортируются и условно рендерятся в корневом компоненте `App.tsx` на основе хука `useIsMobile`.

```tsx
// в src/App.tsx
const isMobile = useIsMobile();

{
  isMobile ? <PerformanceDebugMobile /> : <PerformanceDebug />;
}
```
