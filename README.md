# 4Life Biophysics — Персональный флагман дистрибьютора (Clinical Obsidian)

Персональный сайт официального дистрибьютора 4Life Research Александра Тощева (ID 12299550, склад РЦ 67, Москва) с каталогом из 17 формул рынка Евразии, интерактивной схемой заказа, научной базой Трансфер Факторов и моделью партнёрства.

## Технологический стек

- **React 18** + **TypeScript** (`strict: true`, `noUncheckedIndexedAccess: true`)
- **Vite 6**
- **Tailwind CSS 3.4** (`tailwind.config.js` + `postcss.config.js`)
- **GSAP 3.13** (`ScrollTrigger`) + **Framer Motion 11** + **Lenis 1.3**
- **OGL / WebGL2 Fluid Engine** (3-Tier Adaptive Architecture: High / Medium / Low)
- **Swiper 12**

## Быстрый старт

```bash
npm install
npm run dev
```

Сборка для продакшена и проверка типов:

```bash
npm run typecheck
npm run build
```
