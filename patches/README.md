# Документация для патчей

В этой директории хранятся патчи для сторонних библиотек, созданные с помощью `patch-package`. Патчи применяются автоматически после `npm install`.

--- 

### 1. `webgl-fluid-enhanced`

- **Файл патча:** `webgl-fluid-enhanced+0.8.0.patch`
- **Версия библиотеки:** `0.8.0`

#### Проблема:

Встроенный в библиотеку анимационный цикл искусственно ограничивал максимальный "шаг" времени (`deltaTime`) значением `0.016666` (эквивалент 60 FPS). Это приводило к тому, что на устройствах, где FPS падал ниже 60, анимация не просто становилась менее плавной, а **физически замедлялась**, создавая эффект "slow-motion".

#### Решение:

В файле `node_modules/webgl-fluid-enhanced/dist/index.es.js` была найдена строка:

```javascript
return e = Math.min(e, 0.016666), this.lastUpdateTime = t, e;
```

Она была заменена на:

```javascript
return (e = Math.min(e, 0.1)), this.lastUpdateTime = t, e;
```

#### Результат:

Ограничение `deltaTime` было поднято до `0.1` (эквивалент 10 FPS). Теперь, если производительность устройства падает, анимация сохраняет свою **реальную скорость**, становясь менее плавной, но не замедляясь. Это обеспечивает корректное и предсказуемое поведение эффекта на всех устройствах, особенно на мобильных.
